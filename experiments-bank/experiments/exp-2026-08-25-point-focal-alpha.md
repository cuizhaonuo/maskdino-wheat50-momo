## 预期对账

**标定预测命中。** ideas 里按 focal 平衡点算出 0.318 / 0.413 / 0.514，
实测 0.324 / 0.461 / 0.565 —— 单调性和量级都对，理论模型成立。

**判别力预测落空。** AUC 在 0.72 附近**饱和**：α=0.5 相对 baseline +0.048，
α=0.75 不但没继续涨反而略降（0.7136）。置信度一路上升而 AUC 不动，
正是「纯标定平移」的形态。

**最佳 mF1 几乎不动**：0.3648 → 0.3680 → 0.3670。α=0.5 的 +0.0032
**低于噪声地板 0.008**，不构成真实改善。

## 判否线的一处校准错误（需要记录）

ideas 里写的判否线是「若跨实例 AUC 仍停在 **0.72** 附近（±0.03），说明 α 只是平移标度」。
实测 α=0.5 的 AUC 恰好是 0.719 —— 字面上正中判否线。

但那个 0.72 抄自 [exp-2026-08-25-slot-specialization](exp-2026-08-25-slot-specialization.md)，
是**未加权**的逐 slot AUC 均值；本次探针用的是**按支持度加权**的均值，
同一口径下同期 baseline 是 **0.671**。所以正确的对账不是「停在 0.72」，
而是「相对自己的对照 +0.048，且不随 α 放大」。

**结论不变（判否线成立），但下次写判否线必须连同度量口径一起写死。**

## 结论

α 是一个**有效的标定旋钮，不是判别力手段**。

它把置信度分布整体右移，因此**工作点也跟着右移**：点数与 GT 相当的阈值
baseline 在 0.30、α=0.5 在 0.40、α=0.75 在 0.50。在各自的最优阈值上：

- **mF1 几乎不动**（0.3648 → 0.3680 → 0.3691，两个增量都低于噪声地板 0.008）
- **计数明显改善**（7.61 → **6.02** → **6.57**，即 −21% / −14%）

所以 α 对**计数**是有真实收益的，对**定位**没有。这与「标定而非判别力」的定性一致：
分布右移把正负样本拉开了一点距离，计数（只数个数）受益，定位（要位置准）不受益。

不过同样的标定效果**调阈值就能拿到且不需要重训**——baseline 把阈值从 0.35 挪到 0.30
点数就从 842 变成 1251。除非有必须固定阈值的部署约束，否则不推荐用 α 做这件事。

### 【2026-08-25 订正】原先的计数结论是阈值选点造成的假象

本文档初版只扫了 `{0.20, 0.28, 0.35}`，据此写了「α 毁掉计数，MAE 从 7.61 恶化到 15.38」。
那是在**远离 α 系列工作点**的地方测的：α=0.75 的点数要到 0.50 才与 GT 相当。
补扫到八档 `{0.10,0.15,0.20,0.28,0.35,0.40,0.50,0.60}` 后，
六个 run 的 mF1 峰与计数最优**全部落在区间内部**，结论改为上文。

教训：**每个 run 的最优阈值不同，固定阈值的横向对比会系统性地惩罚分布右移的那些 run。**
`exp-2026-08-21-pointloss-only` 早就警告过 0.35 在悬崖上，我第一次仍然只扫了它附近。

## 注意事项

- overfit10 train==test，端到端指标是拟合质量。
- α 同时作用于内层匹配代价 `cost_class`。实测 F1 前缀一致性两个 α 都是 0.000、
  F3 单调性 0.285/0.291（baseline 0.247），说明**分配结构基本没变**，
  该耦合在本实验中未造成混淆。

## 【2026-08-26 补充】val 泛化检验

[exp-2026-08-26-val-generalization](exp-2026-08-26-val-generalization.md)：alpha050 / alpha075 的 val 最佳 mF1 = **0.1450 / 0.1493**，baseline 为 **0.1495** ——

计数收益部分存活：val 最佳计数 MAE **6.35 / 6.84**，baseline 8.60（−26% / −20%）。

结论方向不变（标定类改善），但须补一句：
**训练集上的 mF1 数字不具备能力含义**，引用本文档时只应引用计数一列。
