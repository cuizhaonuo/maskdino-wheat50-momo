### 与基线的差距怎么随训练变化（预注册的观察量）

- 22 次可比评估中 21 次 KMO 领先，唯一落后的是 44 ep（−0.0007）；52 ep 起 13 次全部领先。
- **差距在收窄**：前半程（≤ 48 ep）在 +0.00 ~ +0.08 之间大幅摆动；52 ~ 80 ep 为 +0.02 ~ +0.04；
  最后 4 轮（88 ~ 100 ep）稳定在 +0.013 ~ +0.016，均值 **+0.0146**，恰好落在 0.015 的噪声地板上。
- 与 50 epoch 对比，末段平台的差距从 +0.024 收窄到 +0.015，缩小了约 40%：

| | 50 epoch | 100 epoch |
|:--|--:|--:|
| 基线 `matched_F1@8` 峰值 / 末值 | 0.5783 / 0.5718 | 0.6331 / 0.6312 |
| KMO `matched_F1@8` 峰值 / 末值 | 0.5962 / 0.5954 | 0.6529 / 0.6454 |
| 末 4 轮均值之差 | **+0.0241** | **+0.0146** |
| `bbox/AP` 末值之差 | **+1.97** | **−0.41** |

**读法**：两种解释都部分成立。50 epoch 的领先有相当一部分是「收敛更快」——基线训练充分后差距缩小，
`bbox/AP` 的 +1.97 更是完全消失；但并没有缩到零，100 epoch 末段仍稳定领先约 0.015。
这个残余量与噪声地板一样大，单种子分辨不了它是不是真的（因此是「未决」，不是「判否」）。

训练末段（iter 11999–12499 均值）的点损失：`loss_point_coord` 0.3366 vs 基线 0.3418，
`loss_point_cls` 0.1196 vs 0.1279，`loss_point_knn` 0.0809（折合原始值 0.0162）。

## 机制诊断（M1′ / M2，预注册）

工具与参数同 50 epoch：`myscripts/backup/vis_process/kmo_match_diag.py`，mini train，100 个 batch，seed 0，
1586 个有点实例 / 24766 个点，只看最后一层 decoder 的内层匹配。

| | 48 ep（iter 5999） | 最终 | 预注册线 | 参照：50 epoch 最终 |
|:--|--:|--:|:--|--:|
| **M1′** 实例内 Pearson r | 0.49 | **0.54** | ≥ 0.3 ✅ | 0.47 |
| **M2** 推翻率 | 15.6% | **12.6%** | ≥ 1% ✅ | 21.4% |
| 换 tie 率 | 0.57% | 0.63% | | 0.38% |
| 推翻时 Eq.2 代价差（中位） | 0.060 | 0.068 | | 0.055 |
| 旧 M1：L1-only 配对下 mean\|ŷ^k − y^k\|（只报告） | 0.0187 | 0.0171 | 旧线 0.0158 | 0.0189 |
| 逐穗水平偏差 | 0.0122 | 0.0104 | | 0.0121 |
| 实例内 std：ŷ^k / y^k | 0.0136 / 0.0235 | 0.0140 / 0.0235 | | 0.0132 / 0.0235 |

- **机制确实在起作用**：`ŷ^k` 的穗内信号随训练持续变强（r：50 epoch 末 0.47 → 本跑 48 ep 0.49 → 100 ep 0.54），
  KMO 到最后仍推翻约八分之一实例的 L1 配对，推翻都发生在近乎打平的候选之间（代价差中位 0.068，折合 L1 距离约 0.014）。
- 推翻率随训练下降（50 epoch 冒烟 run 的 iter 60 时 99% → 50 epoch 正式 run 末 21% → 本跑末 13%）：坐标头越准，L1 越少出现平局，KMO 能插手的机会也越少。
  这和端到端差距在后半程收窄是一致的。

## 计数：两臂都系统性多数，差异主要是标定偏移

|:--|--:|--:|--:|:--|--:|
| 基线 | 578 | 2.60 | **+2.41** | 85.3% / 8.3% / 6.4% | 11.2% |

与 50 epoch 的结论一样：KMO 多出的 0.22 MAE 大致等于它多出的 0.28 偏差，存在性头整体略偏高。
**`count_MAE_spike` 在固定阈值 0.35 下主要反映标定**，要判断是不是真的退步，需要先做阈值扫描、再比 best-vs-best。

## 结论

**预注册判定：「未决」。**

1. **机制在 100 epoch 下成立**：M1′（r = 0.54）与 M2（推翻率 12.6%）都通过。KMO 的上下文代价确实在改变配对，
   `ŷ^k` 学到的穗内结构比 50 epoch 时更强。
2. **端到端增益有相当一部分是「加速」**：末段差距从 50 epoch 时的 +0.024 缩到 100 epoch 的 +0.015（约缩小 40%），`bbox/AP` 的 +1.97 完全消失。
3. **残余的 +0.015 分辨不了**：它恰好等于噪声地板，峰值过线、末值差 0.0008。按用户的决定不补种子，记为未决。
4. **代价**：`segm/AP` 末 4 轮均值 −0.15、`bbox/AP` −0.29（都在平台摆幅内）；计数 MAE/穗 +0.22，主要是标定偏移。
