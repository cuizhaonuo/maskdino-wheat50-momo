## 单变量改动

`POINT_CANONICAL_ORDER=True` 时，在 `_inner_point_match` **内部**分支：
把 Ni 个 GT 小穗按主轴投影排序后返回恒等分配，替代匈牙利匹配。

两个实现要点（均在 ideas 文档里跑之前写死）：
- PCA 在**还原纵横比之后**做（`gt_rel * (bw,bh)`），否则细长穗被拉成方形、主轴方向失真。
- 定向用**纯 `v[1]>0`**（一律自上而下），不用「比较 |v[0]| 与 |v[1]| 再定号」——
  后者在水平翻转增广下会把偏水平实例整体反序。本批 overfit10 设了 `RANDOM_FLIP: "none"`，
  翻转不生效；但真实配置走 detectron2 默认的 `horizontal`，所以必须一开始就写对。

单元测试覆盖：竖直/乱序、45°、水平翻转等变性、细长框、Ni=0/1、全部重合。

## 结果：机制完全按设计工作

| 判据 | baseline | **canonical** | ideas 里写的目标 |
|:--|--:|--:|:--|
| F1 前缀一致性 | 0.000 | **0.762** | >0.9 |
| F1 Spearman(logit, −k) | 0.062 | **0.779** | ≈ −1（符号相反，量级达标） |
| F2 跨实例 AUC | 0.6714 | **0.8421** | >0.85（接近） |
| F3 坐标铺开比 | 0.994 | 0.965 | ≈1 |
| **F3 slot→位置单调性** | 0.247 | **1.000** | ≈1 |

存在性头学会了单调前缀，坐标头学会了 slot→位置 的映射（单调性满分）。
**ideas 里写死的否决条件（`F1>0.9` 且 `F3铺开<0.3`）未触发** —— F3 铺开比 0.965，远不是塌陷。

## 结果：但端到端指标反而变差

| | baseline | canonical |
|:--|--:|--:|
| 最佳 mF1（八档扫描） | **0.3648** @0.28 | 0.2784 @0.28 |
| 最佳 count_MAE_spike | 7.61 @0.35 | **1.62** @0.35（六个 run 最佳） |
| F1@3 @0.35 | 0.2158 | 0.1195 |
| **count_MAE_spike** | 7.61 | **1.62** |
| 预测点数（GT 1178） | 842 | 1065 |
| `loss_point_coord` | 0.1016 | **0.5401** |

**计数是六个 run 里最好的（MAE 提升 4.7 倍），定位是最差的。** 两个目标被劈开了。

## 为什么定位变差：不是塌陷，是欠训练

坐标损失收敛值 0.5401，是 baseline 的 5.3 倍。但看轨迹：

| iter | 1199 | 1399 | 1599 | 1799 | 1999 |
|--:|--:|--:|--:|--:|--:|
| canonical | 0.6612 | 0.6046 | 0.5714 | 0.5316 | 0.5401 |

1199→1799 稳定下降 19.6%，然后走平——**转折点恰好是 `STEPS=(1600,1900)` 的两次 LR 衰减**，
`iter≥1600` 之后只变了 −1.2%。所以平台是**学习率调度结束**造成的，不是问题收敛。
按 ideas 里预先写死的规则，这种情况**只能判「未收敛」，不得判否决**。

机制上也说得通：匈牙利总能挑最近的预测点去配，L1 容易压低但不携带 slot 语义；
恒等分配要求 slot k 命中**特定**那个小穗，是难得多的回归问题，需要更长 schedule。

## 与 exp-2026-08-20-stage2-baseline 的关系

当年 `COST_POINT_*: 0.0` 意外造成恒等分配，计数漂亮（MAE 2.30）但坐标塌陷到中轴线，
结论被撤回为「bug 的产物」。本实验是**同一个存在性目标 + 修正后的坐标语义**：

- 计数同样好（1.62，甚至更好）—— 说明当年那个计数**不是 bug 的产物，是单调前缀目标的真实效果**，
  值得对那条撤回补一句限定。
- 坐标这次**没有塌陷**（F3 铺开比 0.965、单调性 1.000），当年的塌陷确实源于标注顺序不一致
  （实测 980 个实例中仅 59.8% 沿轴同向、9.8% 完全反向、23.7% 无序）。

## 下一步

1. **延长 schedule 复跑**（`MAX_ITER 6000 STEPS (4800,5600)`）。这是唯一能把
   「未收敛」和「代价固有」分开的实验，优先级最高。
2. 若定位仍追不平，则本方案定位为**专用于计数**的配置，与 clsmlp 组合（两者机制正交：
   一个改目标结构、一个加头容量）。
3. ideas 里提的**随机符号对照**（规范排序但每实例 50% 概率反向）尚未做，
   它能把「存在性目标可表达性」与「坐标跨实例一致性」两个收益彻底分开。

## 注意事项

- **overfit10 train==test，上述端到端指标是拟合质量不是泛化。**
- 恒等分配下「slot k 被匹配 ⟺ k < Ni」是构造出来的恒等式，
  **slot 频率诊断对本实验自动等于完美阶梯，不得当作成功证据**（ideas 已预先声明）。
  本文档使用的 F1/F2/F3 均不受该恒等式影响。
- slot 24~49 永远只收到负样本监督，其坐标输出无定义，不要采信。

> **阈值口径**：本文档所有「最佳」均取自八档扫描
> `{0.10,0.15,0.20,0.28,0.35,0.40,0.50,0.60}`，六个 run 的峰值均落在区间内部。
> 原始数据 `exp-2026-08-25-batch-sweep.json`。**每个 run 的最优阈值不同，
> 不要固定在 0.35 上做横向对比**——那会系统性惩罚置信度分布偏右的 run。
