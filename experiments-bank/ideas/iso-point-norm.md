# 想法：小穗点误差改用各向同性归一化

状态：**待验证** ｜ 提出 2026-09-23 ｜ 分支 `mini/iso-norm`（从 `mini/baseline` 拉出）｜ 配置
`wheat_joint_single_stage_mini_iso.yaml` ｜ 输出 `output_v2/exp-0923-mini-iso-norm`

来源：GroupPose 结合方案讨论（E1）。分组 decoder（`mini/group-decoder`，E3）也用这一改动，
本实验在现有 MLP 点头上单独量它的作用。

## 现象

内层匹配代价与坐标 L1 都在「框相对坐标」里算：`gt_rel = (gt − xy0) / (w, h)`（`criterion.py` 的 `loss_points`）。
x 误差除以 w、y 误差除以 h，**两轴权重之比等于框的长宽比**。实测（coco_2cat_with_points train，5394 个 wheat_2）：

| 量 | 值 |
|:--|--:|
| 框长宽比 long/short | p10 1.3 / **p50 2.3** / p90 3.7 |
| 沿穗轴相邻小穗间距（按主轴投影排序后的步长） | 中位 **9.5 px** |
| 两列小穗横向间距 | 中位约 17 px |
| 同穗最近邻间距 | 中位 16.9 px |

穗大多沿框的长边方向，所以沿轴误差落在长边上、权重最低；而最容易「张冠李戴」的恰恰是沿轴方向
（相邻 9.5 px，已逼近 σ=8 的判定线）。**现行损失在最难的方向上用力最小。**

## 修法

`cfg.MODEL.MaskDINO.POINT_COORD_NORM`：`box_axis`（现状，默认）| `iso`。
`iso` 时误差乘以逐轴因子 `(w, h)_px / sqrt(w·h)_px`，即「像素误差 / sqrt(w·h)」，两轴同权；
框的像素纵横比用新加入 targets 的 `image_wh` 还原（LSJ 训练输入恒为 1024²，二者等价）。
内层匹配代价、坐标 L1、两个诊断钩子同时切换，始终在同一空间。
`sqrt(w·h)` 是 w、h 的几何平均，损失量级与原来相近，所以两项坐标权重（5.0）不动。

例：75×309 px 的框，8 px 误差在 box_axis 下沿 x 为 0.107、沿 y 为 0.026（差 4.1 倍）；在 iso 下两轴都是 0.053。

## 实施前已完成的验证

- **回归**（qiuhao GPU0，同种子、同 batch、1 次训练态前向）：`POINT_COORD_NORM=box_axis` 时与主仓库
  `exp/single-stage-joint-mini` 的 **127 项 loss 逐位相等**，参数量同为 52,300,433。
- **开启**：`iso` 时 `loss_point_coord` 由 1.709 变为 2.29（初值，量级如预期相近），其余损失不变。

## 预期与判否线（跑之前写死）

对照 mini/baseline（`output_v2/exp-0922-single-stage-mini`），唯一差别是 `POINT_COORD_NORM`：

| 指标 | 峰值 | 末值 |
|:--|--:|--:|
| `matched_F1@8` | 0.5783（iter 4499） | 0.5718 |
| `segm/AP` | 73.67（iter 5749） | 73.52 |
| `count_MAE_spike` | 3.81 | 3.88 |

### 机制（先判）

对 val 上配对的 wheat_2（mask IoU ≥ 0.5），沿用评估器同一套点级匈牙利配对，把每个配对点的误差向量
投影到该 GT 穗的主轴（GT 点 PCA）上，分别报沿轴 / 横轴绝对误差的中位数（最终 checkpoint，两臂同一阈值 0.35）。
脚本：`mini/group-decoder` 分支的 `myscripts/backup/vis_process/point_token_diag.py`（该分支代码开关关着时与基线逐位一致，
可分析任一臂的 checkpoint）。自检：它用同一批配对重算的 matched_F1@8 在 mini/baseline 最终 checkpoint 上为 0.57183，
与训练日志的 0.5718 一致。

mini/baseline 最终 checkpoint 的实测值（跑 E1 之前测得）：

| | 沿轴中位 | 横轴中位 | 配对点数 |
|:--|--:|--:|--:|
| 全部配对 | **4.65 px** | **2.90 px** | 8837 |
| 仅距离 ≤ 8 px 的配对 | 3.19 px | 2.25 px | 5672 |

沿轴误差确实是横轴的 1.6 倍，与「沿轴方向权重最低」的假设方向一致。

- **M1**（全部配对口径）：沿轴误差中位数 ≤ **4.19 px**（比基线低 ≥ 10%），且横轴误差中位数 ≤ **3.19 px**（升幅 ≤ 10%）。
  M1 不通过 → 判「机制未启动」，端到端差异不归因于归一化。

### 主判据：`matched_F1@8`

| 条件 | 判定 |
|:--|:--|
| 峰值 ≥ **0.5883** 且末值 ≥ **0.5818**（基线 +0.01），护栏满足 | **成立** |
| 峰值 ≤ 0.5783 | **判否** |
| 介于两者之间 | **歧义**：种子方差从没测过，单种子分辨不了 0.01 以内的差异 |

### 护栏与观察量

- 护栏：`segm/AP` 峰值 ≥ **73.17**；`count_MAE_spike` 峰值 ≤ **4.19**。
- 观察：`matched_F1@3` / `@5` 的变化应当比 `@8` 更明显（改的是精细定位）；只记录，不作判据。
- 固定 `POINT_THRESHOLD=0.35` 下比较；若主判据落在歧义区，再对两臂的最终 checkpoint 做阈值扫描、比 best-vs-best。

## 归因限制

只改了误差的几何，存在性损失未动；但内层配对随之改变，存在性目标（哪些 slot 为正）也会随之改变。

## 成本

6250 iter，约 7 h（与基线同配置）。

## 结论（2026-09-24，按上面写死的规则判）

**主判据歧义；阈值扫描后 best-vs-best 刚过 +0.01；机制判据 M1 未通过 → 端到端的小幅改善不能归因于「沿轴加权」。**

输出 `output_v2/exp-0923-mini-iso-norm`（xuyu GPU0，6250 iter 跑完，0 报错）。诊断 `output_v2/_diag-0924/`。

| | mini/baseline | E1 iso | 差 |
|:--|--:|--:|--:|
| `matched_F1@8` 峰值 / 末值 | 0.5783 / 0.5718 | 0.5881 / 0.5864 | +0.0098 / +0.0146 |
| 最后 5 轮均值 | 0.5710 | 0.5856 | +0.0146 |
| 阈值扫描最优（最终 checkpoint） | 0.5794 @0.30 | 0.5899 @0.25 | +0.0105 |
| `matched_F1@5` / `@3` 末值 | 0.3063 / 0.1298 | 0.3093 / 0.1249 | +0.003 / −0.005 |
| `count_MAE_spike` 峰值 / 末值 | 3.81 / 3.88 | 4.12 / 4.16 | 变差 +0.3 |
| `segm/AP` 峰值 / 末值 | 73.67 / 73.52 | 74.15 / 74.15 | +0.5 / +0.6 |
| 沿轴 / 横轴误差中位数（全部配对） | 4.65 / 2.90 px | 4.25 / 3.12 px | −8.7% / +7.4% |
| 同上，仅距离 ≤ 8 px | 3.19 / 2.25 px | 3.12 / 2.39 px | −2.3% / +6.4% |

- **主判据**：峰值 0.5881 差成立线 0.5883 仅 0.0002，末值 0.5864 过线（0.5818）→ 按规则为**歧义**。
  最后 8 轮 E1 全部高于基线 0.01~0.017，方向一致，但单种子、种子方差未测。
- **阈值扫描**（歧义区的预定补充）：best-vs-best +0.0105；0.10~0.40 各档 E1 都高于基线，0.45 以上反过来。
- **M1 未通过**：沿轴误差降 8.7%（要求 ≥ 10%），且降幅几乎全来自远处配对（≤ 8 px 的配对只降 2.3%）；
  精细定位 `@3` 反而略差。按规则判「机制未启动」：matched_F1@8 的提升不归因于沿轴加权。
- **护栏**：`segm/AP` 峰值 74.15 ≥ 73.17 ✓；`count_MAE_spike` 峰值 4.12 ≤ 4.19 ✓（但计数确实变差约 8%）。

读法：各向同性归一化带来约 +0.01 的 `matched_F1@8`（在种子方差量级），代价是计数变差约 0.3。
不建议单独作为改进项；它在分组 decoder（E3）里的作用需结合 E3 与 E2 的对比看。
