# 想法：GT 小穗点规范排序，把存在性目标简化成单调前缀

状态：**成立（泛化检验后为本批唯一实质收益）** ｜ 提出 2026-08-25 ｜ 验证于
[exp-2026-08-25-point-canonical-order](../experiments/exp-2026-08-25-point-canonical-order.md)

## 现象

两个独立事实拼在一起才看清：

1. [exp-2026-08-25-slot-specialization](../experiments/exp-2026-08-25-slot-specialization.md)：
   内层匹配**高度稳定**（Jaccard 0.998），slot 却只有部分分化（频率 std 0.1814
   对完美分化的 0.4113），存在性头只学到边际频率、跨实例 AUC 仅 0.721。
   即目标稳定可学，但头没学到。
2. [exp-2026-08-20-stage2-baseline](../experiments/exp-2026-08-20-stage2-baseline.md)：
   当年 `COST_POINT_*: 0.0` 导致恒等分配，坐标头**塌陷到穗中轴线**。

## 假设

现在存在性头要学的目标是「84 个实例各自任意的一组 50 位模式」——
哪些 slot 为正取决于预测点恰好落在哪，是坐标头输出的复杂函数。
若把 GT 小穗点按穗轴排序、slot k 固定监督第 k 个点，目标退化成
**`slot k 亮 ⟺ k < Ni`**，头只需从 embedding 读出 `Ni` 这一个标量，
单层 `nn.Linear` 完全可表达（`logit_k ≈ c·(s(q) − t_k)`，共享方向 + 递减偏置）。

**这条与 baseline 的恒等分配的区别，正是「规范」二字。** 离线实测 980 个有点实例：

| 量 | 值 |
|:--|--:|
| 第一主成分解释方差 | mean 0.941 / median 0.953，86.9% 的实例 >0.9 |
| 标注顺序 vs 沿轴（自上而下）排序的秩相关 | 59.8% >0.95，9.8% <-0.95，**23.7% \|corr\|<0.5** |

小穗**确实排成一条线**，但标注（LabelMe 点击）顺序方向不一致、四分之一根本无序。
baseline 的恒等分配让 slot k 在不同实例里含义不同，L1 下的最优解就是均值 → 中轴线。
规范排序把这个含义钉死，是 baseline 缺的那一环，不是回退到 baseline。

## 修法

新增 `cfg.MODEL.MaskDINO.POINT_CANONICAL_ORDER`（默认 False）。
为 True 时在 `_inner_point_match` **内部**分支（该函数有 3 个调用点，
两个诊断脚本承诺「画的就是 loss 真正用的那组配对」，分支放里面才不会说谎）：
按主轴投影排序后返回恒等分配。

两个必须做对的细节：

- **PCA 要在还原纵横比之后做。** `gt_rel` 已被 `(bw,bh)` 归一化，细长穗被拉成方形。
  训练输入是 `FixedSizeCrop(1024,1024)`，W==H，所以 `gt_rel * (bw,bh)` 恰好还原到
  各向同性的图像归一化空间。对严格共线的点，线性映射保序，排序结果其实不变；
  但它会影响**定向判据**和 6~13% 非共线实例的主轴方向。
- **定向用纯 `v[1]>0`（一律自上而下），只在恰好水平时用 x 兜底。**
  不能用「比较 |v[0]| 与 |v[1]| 再定号」——那个规则在水平翻转增广下会把所有偏水平的
  实例整体反序（`x→-x` 时 `v=(a,-b)` 变成 `(a,b)`，投影整体变号）。
  纯 `v[1]>0` 规则对水平翻转是等变的。本批实验用的 overfit10 配置设了
  `RANDOM_FLIP: "none"`，翻转不生效；但真实配置 `wheat_stage2_pointhead.yaml`
  没设该项、走 detectron2 默认的 `horizontal`，所以这条必须一开始就写对。

**推理侧不动。** 保留逐 slot 阈值。若规范排序生效，存在性头本就该输出单调剖面、
阈值法自然取到前缀，**沿用旧规则反而是对「是否学到单调结构」的检验**；
换成前缀规则会无论头学没学到都产出前缀，把失败模式掩盖掉。前缀解码留作事后消融。

## 预期与判否线（跑之前写死）

- **坐标损失初值必然远高于 baseline**，这是预期不是失败：匈牙利总挑最近的点去配，
  恒等分配强制 slot k 对第 k 个点。判据看收敛值和点级 F1，不看初值。
- **F1 前缀一致性**：阈值化后的 slot 集合恰好是 `{0..K-1}` 的实例占比，
  以及每实例 `logit_k` 对 `−k` 的 Spearman。预期 >0.9 且 ≈ −1。
- **F2 跨实例 AUC**（逐 slot 算 `logit_k` 区分 `Ni>k` 与 `Ni≤k`，按支持度加权；
  **不能池化**，池化在规范排序下会因边际极端而虚高）。baseline 0.721，预期 >0.85。
- **F3 坐标铺开比**（决定性）：把匹配 slot 的预测坐标投影到 GT 主轴，
  报 `std(预测投影)/std(GT投影)` 与 Spearman(slot序号, 投影)。
  塌陷到中轴 → 比值 ≈ 0、Spearman ≈ 0；成功 → 比值 ≈ 1、Spearman ≈ 1。

**判否线（写成能与「欠训练」区分的形式）：**

> 若 **F1 > 0.9**（存在性头已经把现在可表达的目标学会了，分配不再是瓶颈）
> 而 **F3 的铺开比仍 < 0.3** 且 σ=3px 的点级 P/R 不优于 baseline，
> 则「slot→位置 映射不一致导致中轴塌陷」这一假设被**否决**，
> 瓶颈应转向坐标头容量或 L1-on-框相对坐标 的损失几何。
> 若 F1 与 F3 **同时**偏低，属**歧义**，只能延长 schedule 再判，不得下结论。

- **slot 频率诊断对本实验失效**：恒等分配下「slot k 被匹配 ⟺ k < Ni」是构造出来的
  恒等式，频率必然等于完美阶梯。**不得拿它当成功证据。**
- α 的边际频率从平的 0.28 变成 `P(Ni>k)`（1.0→0.0），各 slot 的 focal 平衡点差异巨大，
  固定阈值 0.35 在两种模式下对应的分位数完全不同。**必须做阈值扫描后比 best-vs-best。**
- slot 24~49 永远只收到负样本监督（全库 max Ni = 24），其 `point_coord_embed` 输出
  无梯度、无定义，不要可视化或采信这些坐标。

## 结论（2026-08-25）

机制**完全按设计工作**：F1 前缀一致性 0.000 → **0.762**，Spearman 0.062 → **0.779**，
F2 跨实例 AUC 0.671 → **0.842**，F3 slot→位置单调性 0.247 → **1.000**。
预先写死的否决条件（`F1>0.9` 且 `F3铺开<0.3`）**未触发**——F3 铺开比 0.965，不是塌陷。

但端到端相反：最佳 mF1 0.3648 → 0.2784，坐标损失 0.1016 → 0.5401。
**计数却是六个 run 里最好的**（`count_MAE_spike` 7.61 → **1.62**）。

坐标损失的平台是 `STEPS=(1600,1900)` 的 LR 衰减造成的（1199→1799 仍降 19.6%，
之后只变 −1.2%），按预先写死的规则**只能判「未收敛」**。
下一步是延长 schedule 复跑，这是唯一能把「未收敛」与「代价固有」分开的实验。

### 【2026-08-26 订正】泛化检验把本条升为本批最佳

[exp-2026-08-26-val-generalization](../experiments/exp-2026-08-26-val-generalization.md)：val 计数 MAE **2.38（baseline 8.60，−72%）**，是六个 run 里唯一实质且可迁移的收益。
作为对照，用 320 张图训练的 innercost 在同一 val 集上是 7.6~8.2，而本条只用了 10 张图。

定位在 val 上仍最低，但六个 run 的 mF1 落差齐为 −59%~−65%，说明 10 张图教不出定位、
那一列没有区分度。有区分度的是计数，而计数正是单调前缀目标的直接产出。

**优先级从「治本但改动大」升为「下一步就做」：上真实配置 + 延长 schedule。**
