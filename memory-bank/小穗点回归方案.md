# 计划：在 MaskDINO 中增加"逐实例小穗点回归"头（端到端）

## Context（背景与目标）

项目 `maskdino-wheat50` 做小麦麦穗实例分割，两类：`wheat`(id1→0) 与 `wheat_2`(id2→1)。
只有 `wheat_2` 麦穗在 COCO 标注里带 `points` 字段（小穗坐标），数据注册已通过
`extra_annotation_keys=["points"]` 加载（`data_register/wheat_data_cat2.py`，`WITH_POINTS=True`）。

**目标**：训练一个**端到端单模型**，对每个 `wheat_2` 实例同时输出实例掩码 + 内部小穗点（坐标与数量），
用于产量估计；`wheat` 实例内部不得出现任何小穗点。

**用户已确认的架构**（嵌套集合预测，放弃此前误留的高斯密度图方案）：
```
decoder 输出 (B, 300, 256)
 ├─ cls_head           (B, 300, 2)          已有
 ├─ box_head           (B, 300, 4)          已有
 ├─ mask_head          (B, 300, H, W)       已有 (einsum mask_embed·mask_features)
 ├─ point_center_head  (B, 300, 50, 2)      新增：每实例最多 50 个小穗点坐标
 └─ point_cls_head     (B, 300, 50, 1)      新增：每个点的存在置信度
```
外层：300 query ↔ GT 实例（沿用现有 `HungarianMatcher`）。
内层：每个被匹配上的实例，其 50 个预测点 ↔ 该实例的 GT 小穗，做二次匈牙利匹配。
`wheat` 实例 GT 小穗数=0 → 内层 50 点全部监督为背景 → **天然保证 wheat 内无点**。
机制上等价于把 CLTR 的"点头 + focal 分类 + L1 坐标 + 匈牙利匹配"嵌进 MaskDINO 每个实例 query。

## 关键设计决定

1. **点坐标采用"实例框相对归一化" [0,1]**：预测点相对 query 的预测框（cxcywh）左上角归一化。
   - 训练：用匹配到的 **GT 框** 把 GT 小穗（图像归一化坐标）转成框相对坐标 `rel=(p_norm-[x0,y0])/[w,h]`，clip 到 [0,1]。
   - 推理：用预测框把框相对坐标还原到图像像素。
   - 理由：把"小穗在穗内的相对分布"与"穗子在图上的位置"解耦，小目标更易学；天然约束点落在穗框内。
   - （备选：整图归一化 + decoder reference 偏移，CLTR 原始做法，接线更简单但回归绝对位置更难。框相对为首选。）
2. **`num_points P = 50`**：每穗预测点上限。实现前先核对数据集中单穗最大小穗数（见验证节命令），
   若 >50 需调大 `NUM_POINTS` 或裁剪。设为 config 项。
3. **DN（去噪训练）不参与点损失**：点头照常对所有 query 计算，但 `dn_losses` 不含 `points`，
   降低复杂度；只在主输出 + aux 层（非 dn 部分）算点损失。
4. **逐 decoder 层深监督**：点头放进 `forward_prediction_heads`，与 mask 一样进入 aux loss。

### 4. `maskdino/modeling/criterion.py`
- `__init__` 增加 `num_points`、`point_cost_coord`、`point_cost_class` 等参数并保存。
- 新增 `loss_points(self, outputs, targets, indices, num_masks)`：
  1. `idx=self._get_src_permutation_idx(indices)` 拿到匹配到的 (batch, query)。
  2. 遍历每个匹配三元组 `(b, query_i, gt_j)`：
     - `pred_rel = outputs['pred_point_coords'][b, query_i]`  `[P,2]`
     - `pred_lg  = outputs['pred_point_logits'][b, query_i]`  `[P,1]`
     - `gt_pts_img = targets[b]['points'][gt_j]`  `[Ni,2]` 图像归一化
     - `gt_box = targets[b]['boxes'][gt_j]`（cxcywh 图像归一化）→ 算 `x0,y0,w,h`
     - `gt_rel = ((gt_pts_img - [x0,y0]) / [w,h]).clamp(0,1)`  `[Ni,2]`
     - 内层匈牙利匹配（cost = `point_cost_coord * cdist_L1(pred_rel, gt_rel)`
       `+ point_cost_class * focal_cost(pred_lg)`，参照 CLTR
       `/public/home/zncui/pycharm_project/CLTR/Networks/CDETR/matcher.py:66-80`）。
     - 累积：匹配点的 L1 坐标损失；全部 P 点的存在性 focal/BCE 损失（匹配→1，其余→0）。
       `Ni==0`（wheat）时无坐标损失、P 点全监督为 0。
  3. 归一化：坐标损失 / 总匹配小穗数；分类损失 / 总小穗数（参照 CLTR `loss_points`/`loss_labels`，
     `conditional_detr.py` focal_loss）。返回 `{"loss_point_coord":..., "loss_point_cls":...}`。
- `get_loss` 的 `loss_map`（326-333 行）注册 `"points": self.loss_points`。
- 内层匹配实现：直接在 criterion 内写一个 `@torch.no_grad()` 小函数（逐实例 `linear_sum_assignment`），
  复刻 CLTR matcher 的 cost 构造，避免改动现有外层 `matcher.py`。

## 需要注意的坑
- **DN 与点头**：`forward_prediction_heads` 对含 dn pad 的 query 一并算点头，务必在 `dn_post_process`
  里对点预测做与 mask 相同的切分，否则外层匹配/损失会错位。点项**不要**进 `dn_losses` 与 `_dn` weight。
- **two_stage / interm**：`interm_outputs` 也会经 `forward_prediction_heads` 产生点预测；`loss_points`
  在 interm/aux 上同样会被调用，需保证 outputs 里有 `pred_point_coords/logits`（已在 `_set_aux_loss` 与
  interm 输出补齐）。
- **空点实例**：内层匹配 `Ni==0` 与 `P>0` 时 `linear_sum_assignment` 退化为全负样本，注意分支处理避免空张量报错。
- **坐标系一致性**：`gt_points` 必须与 `boxes` 用同一 `(w,h)=image_size`（pre-pad）归一化。

## 验证（Verification）
1. **数据健全性 / P 值**：统计单穗最大小穗数，确认 `NUM_POINTS=50` 足够：
   用一个临时 python 读 `instances_train2017.json`，对 `category_id==2` 的 anno 取 `len(points)` 的 max/分布。
2. **mapper 单测**：构造一个 batch 走 mapper，断言 `instances.gt_points` 长度==实例数、wheat 实例点为空、
   wheat_2 点数与标注一致、增广后点仍在图内。
3. **前向 shape**：临时脚本跑一次 `model(batched_inputs)` 训练前向，确认
   `outputs['pred_point_coords'].shape == (B,300,50,2)`、`pred_point_logits == (B,300,50,1)`，loss 字典含
   `loss_point_coord/loss_point_cls`（及 `_i`、`_interm`），且反向不报错。
4. **过拟合小集**：取 5~10 张含 wheat_2 的图，少量 iter 过拟合，确认点损失下降、
   推理时 wheat_2 实例点数≈GT、wheat 实例点数==0。
5. **端到端训练**：`python train_net.py --config-file configs/coco/instance-segmentation/Wheat-COCO-InstanceSegmentation.yaml`
   （沿用现有训练命令），TensorBoard 观察 `loss_point_*` 收敛。
6. **可视化**：推理后把 `pred_spikelet_points` 叠加到原图，肉眼核对小穗定位与计数；
   统计每穗 count 的 MAE/MSE 作为产量评估指标（后续可加入 evaluator）。
